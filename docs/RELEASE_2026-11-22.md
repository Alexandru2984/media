# Media release — 2026-11-22

## Delivered

Application security now protects direct post-image reads using the same current
audience policy as Nginx, rejects unmanaged upload paths and writes, overrides
forged probe headers, fails closed on database failures, and sends private /
no-store plus appropriate response headers independently of the proxy.

Password changes, resets and verified email changes revoke outstanding recovery
and email-change links transactionally. Recovery issuance and credential changes
share an account lock; concurrent reset links have one successful winner.

The public page has an editorial layout, original vector artwork and four
explicitly labeled interactive conversation examples. Authenticated discovery
adds Unicode hashtag links, people/post/all filters, topic entry points, safe
login returns, cancelled stale searches and correct feed continuation after
deduplication. Images have an accessible modal viewer with Escape/backdrop
dismissal, focus containment/restoration, scroll lock and failure states. Feed
sidebars provide useful links instead of generic advice. The global shell,
buttons and branding use a flatter treatment.

## Verification

- Rust: 65 application tests, five seed tests, format and strict Clippy pass;
  optimized locked build passes.
- Disposable MariaDB + actual HTTP: 19 media and 13 identity checks pass. Test
  database, database user, listener and temporary files were removed.
- Frontend: 31 contract tests and build pass; 126,980 entry JS bytes, 83,876 CSS
  bytes, 270,408 total JS bytes. Existing budgets are unchanged.
- Chromium: landing and image viewer at 320/390/768/1440 px in both themes;
  discovery/filter/escaping/request-race/pagination scenarios at all four widths.
  Public Cloudflare rendering and topic interactions at 390/1440 px in both
  themes pass without uncaught JS errors, observed CSP violations or overflow.
- Public, direct-origin and built entry JS/CSS are byte-identical. Production
  services and existing health/backup timers remain active; API unexpected
  restart count is zero. Production still has zero users and posts.
- Tracked Nginx vhost, proxy/security snippets, rate-limit policy and API systemd
  unit match installed files. No infrastructure configuration, schema migration,
  production credential, tracking service or real user content was introduced.

## Unresolved findings and limits

Seven RustSec vulnerability reports were fixed with lettre 0.11.24, url 2.5.9
and SQLx 0.9.1. The full lockfile audit still fails on the optional SQLite
binding; it is absent from the active MySQL build. Chrono also has an
unmaintained warning. Neither was hidden with an audit-ignore rule. The npm
audit reports no findings.

Operator clarification supersedes the earlier SMTP assumption: Brevo was retired
months ago and its restoration/credential rotation are excluded. Current email
delivery is unverified. SMTP transport isolation, account-aware throttling, MFA/passkeys,
strict edge-compatible CSP, privacy governance, broader integration/browser CI
and the remaining product features are open. This release did not claim a full
penetration test, guaranteed security, tested email delivery or a finished
product. Public content indexing remains unchanged.
